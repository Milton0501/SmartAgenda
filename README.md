SmartAgenda

Sistema de gestión de tareas diseñado para el usuario final, enfocado en la organización eficiente y la proactividad.

🚀 Tecnologías
**Backend**: Java con Spring Boot
**Arquitectura**: Basada en capas y metodologías ágiles
**Base de Datos**: PostgreSQL
**Frontend**: Thymeleaf (Plantillas de servidor)

💡 Características principales
* **Asistente Inteligente**: Sistema diseñado para actuar como un copiloto en la gestión de tu agenda diaria.
* **Arquitectura Escalable**: Estructura modular preparada para crecimiento futuro.
* **Seguridad**: Configuración robusta utilizando variables de entorno para proteger credenciales.

🛠️ Cómo empezar
1. Clona el repositorio:
   `git clone https://github.com/Milton0501/SmartAgenda.git`
2. Configura tus variables de entorno (`DB_URL`, `DB_USERNAME`, `DB_PASSWORD`) para conectar con tu base de datos local.
3. Ejecuta la aplicación usando Maven.
